# VincentCRM 后续开发计划

## 一、短期计划（P1 — 建议下一阶段实施）

### 1. 前后端全面联调与 Bug 修复

- **优先级**：最高
- **内容**：逐页面验证所有 CRUD 操作、分页、搜索、详情页
- **重点**：统一前后端 API 路径命名（clue → lead 等）
- **预计工时**：2-3 天

### 2. 数据字典与系统配置

- 数据字典管理（行业、来源、阶段等可配置枚举）
- 系统参数配置（公海规则、跟进超时天数等）
- **预计工时**：1-2 天

### 3. 文件上传与附件管理

- MinIO / OSS 文件存储集成
- 头像上传、合同附件、跟进附件
- **预计工时**：1 天

### 4. 操作日志

- AOP 切面记录关键操作日志
- 工作台"最近动态"改为从操作日志获取
- **预计工时**：1 天

### 5. 数据导入导出

- Excel 导入 / 导出（EasyExcel）
- 线索批量导入、客户导出
- **预计工时**：1-2 天

## 二、中期计划（P2 — 功能增强）

- 业绩排行榜
- 回款统计

- 自定义数据范围（跨部门协作）

## 五、开发指南（给后续 AI / 开发者的提示）

### 环境准备

```bash
# 启动基础设施
docker compose up -d

# 启动后端
cd backend && mvn spring-boot:run -pl app

# 启动前端（需要 Node 22）
export PATH="/opt/homebrew/opt/node@22/bin:$PATH"
cd frontend/packages/web && pnpm dev
```

### 开发约定

- 新模块包名：`cn.vincent.crm.{moduleName}`
- 结构：controller / domain / dto（request + response） / mapper / service
- Flyway DDL 放 `migration/V1.0.0/ddl/`，DML 放 `dml/`
- 表名加 `crm_` 前缀
- 权限追加到 `PermissionConstants.java`
- i18n 追加到 `messages_zh_CN.properties` 和 `messages_en_US.properties`

### 默认账号

- `admin` / `CordysCRM`
