# CordysCRM UI Design Prompt Specification

> **Version**: v1.0  
> **Last Updated**: 2026-05-19  
> **Target Platform**: Desktop Web (min-width 1280px) + H5 Mobile (Vant-UI)  
> **Design Reference**: Flat Design (极简扁平化) + Naive UI Design System  

---

## 1. Layout — 主体与布局

### 1.1 整体架构

采用经典的三栏式 CRM 布局：**顶部导航栏 (Header)** + **左侧菜单栏 (Sider)** + **右侧内容区 (Content)**。页面整体高度 100vh，无全局滚动，内容区内滚动。

```
┌─────────────────────────────────────────────────────────┐
│  Top Header (56px)                                      │
│  [Logo] [TopMenu Tabs] ---- [Search] [Follow] [Lang]   │
│  [Alert] [Agent] [Version] [Avatar]                     │
├──────────┬──────────────────────────────────────────────┤
│  Sider   │  Content Area                                │
│  (180px  │  ┌────────────────────────────────────────┐  │
│  /56px   │  │  Breadcrumb + Page Title + Actions     │  │
│  collap) │  ├────────────────────────────────────────┤  │
│          │  │  Filter Bar / View Switcher             │  │
│  [Menu   │  ├────────────────────────────────────────┤  │
│   Items  │  │                                        │  │
│   with   │  │  Core Content                          │  │
│   Icons] │  │  (Data Table / Kanban / Detail)        │  │
│          │  │                                        │  │
│          │  ├────────────────────────────────────────┤  │
│  ──────  │  │  Pagination                            │  │
│  [Avatar]│  └────────────────────────────────────────┘  │
│  [Name]  │                                              │
└──────────┴──────────────────────────────────────────────┘
```

### 1.2 顶部导航栏 (Header — 56px)

- **左侧区域**：品牌 Logo（高度 28px，区域最小宽度 180px / 最大 300px，水平居中，左右 padding 24px）
- **中部区域**：一级模块 TopMenu Tab 切换（工作台、线索、客户、商机、合同、产品、仪表板、系统设置），激活态底部 2px 主色指示条
- **右侧区域**（从左到右排列，间距 8px）：
  - 全局搜索按钮（放大镜图标，16px，点击弹出搜索抽屉）
  - 跟进计划按钮（日历图标，16px，带权限控制）
  - 语言切换（地球图标，下拉选择中/英文）
  - 通知铃铛（带红点 Badge 未读提示）
  - AI Agent 入口（机器人图标，16px，点击弹出 AI 对话抽屉）
  - 版本信息（Popover 卡片，宽度 320px）
  - 用户头像与下拉菜单

### 1.3 左侧菜单栏 (Sider — 180px / 收起 56px)

- **展开态 (180px)**：带图标的菜单树，root-indent 24px，子级缩进 38px（有图标时）或 8px（无图标时），图标尺寸 18px
- **收起态 (56px)**：仅显示图标，图标尺寸 28px，悬浮 Tooltip 显示菜单名称
- **底部区域**：用户头像（40px 展开 / 25px 收起）+ 用户名 + 下拉菜单（个人信息、API Key、退出登录），背景色 `var(--text-n9)`，hover 态 `var(--primary-7)`
- **折叠触发**：Sider 底部折叠按钮，点击切换展开/收起，带 `collapse-mode="width"` 过渡动画

### 1.4 内容区 (Content)

- **面包屑 + 标题行**：左侧面包屑导航 + 页面标题（font-semibold 16px），右侧操作按钮组（新增、导入、导出、批量操作等）
- **筛选栏**：条件筛选下拉、搜索输入框、视图切换（列表视图 / 看板视图）、高级筛选按钮
- **核心内容**：
  - **列表视图**：Naive UI DataTable，行高 48px，斑马纹可选，支持多选 Checkbox、排序、列宽拖拽
  - **看板视图**：水平多列卡片布局，每列代表一个阶段（如商机阶段：初步接触 → 需求确认 → 方案报价 → 赢单 → 输单），卡片支持拖拽排序（vue-draggable-plus）
  - **详情页**：顶部信息卡片 + 下方 Tab 标签页（基本信息、联系人、商机、合同、回款、发票、订单、跟进记录等）
- **分页器**：右下角固定，每页条数可选（10/20/50/100）

### 1.5 特殊页面布局

- **登录页**：全屏居中布局，左侧品牌插画区域（60%宽，纯色背景）+ 右侧登录表单区域（40%宽），无渐变
- **仪表板 (Dashboard)**：全屏无边距，独立 Header 带 Logo，可拖拽组件网格布局
- **AI Agent 对话**：右侧抽屉式面板，宽度 420px，对话气泡式布局
- **审批流编辑器**：基于 @antv/x6 的流程图编辑画布，全屏模式

## 2. Style — 视觉风格

### 2.1 设计风格定义

**极简扁平化风格 (Minimalist Flat Design)**

- 整体视觉基调：纯粹、克制、高效，以白色为底色，主色点缀，强调内容本身而非装饰，追求信息密度的最优解
- 严格扁平化：不使用阴影、渐变、拟物化纹理等任何模拟物理深度的手法，通过边框、背景色差异、分隔线建立层级关系
- 层级表达策略：以「边框 + 背景色差异」替代阴影，以「色彩对比」替代立体感，以「留白」替代装饰
- 参照 Naive UI 默认设计语言，深度定制主题色与中性色阶，移除所有投影与渐变

## 3. Components — 组件细节

### 3.1 按钮 (Button)

基于 Naive UI Button 深度定制：

| 类型 | 默认态 | 悬停态 | 按下态 | 禁用态 |
|-----|-------|--------|--------|--------|
| **Primary** | bg: `#1E88E5`, text: `#FFF` | bg: `#1565C0` | bg: `#0B3D91` | bg: `#64B5F6` |
| **Secondary** | bg: `#E8E8E8`, text: `#1F1F1F`, border: `#E8E8E8` | bg: `#F5F5F5`, border: `#F5F5F5` | bg: `#D9D9D9`, border: `#D9D9D9` | text: `#BFBFBF`, bg: `#F5F5F5` |
| **Outline Primary** | border: `#1E88E5`, text: `#1E88E5` | border: `#1565C0`, text: `#1565C0`, bg: `#E3F2FD` | border: `#0B3D91`, text: `#0B3D91`, bg: `#E3F2FD` | border: `#64B5F6`, text: `#64B5F6`, bg: `#FFF` |
| **Text Primary** | text: `#1E88E5`, bg: `transparent` | text: `#1E88E5`, bg: `#E3F2FD` | text: `#1E88E5`, bg: `#BBDEFB` | text: `#64B5F6` |
| **Danger** | bg: `#F44336`, text: `#FFF` | bg: `#E53935` | bg: `#C62828` | bg: `#EF9A9A` |

**按钮尺寸**:

| 尺寸 | 高度 | 内边距 (左右) | 字号 | 圆角 |
|-----|------|-------------|------|------|
| Small | 28px | 12px | 13px | 2px |
| Medium | 34px | 16px | 14px | 2px |
| Large | 40px | 20px | 14px | 2px |

**按钮过渡**: `all 0.15s ease`

### 3.2 卡片 (Card)

- **默认态**: 背景 `#FFFFFF`, 圆角 4px, 无阴影, 1px 边框 `#E8E8E8`
- **悬停态**: 边框颜色加深至 `#D9D9D9`, 背景不变, 无位移
- **选中态**: 左侧 3px 主色指示条 `#1E88E5`, 背景 `#E3F2FD`, 边框 `#1E88E5`
- **内边距**: 16px (lg)
- **卡片间距**: 16px (lg)
- **看板卡片**: 宽度 280px, 内边距 12px, 1px 边框 `#E8E8E8`, 无阴影; 拖拽时边框 `#1E88E5`, 无旋转

### 3.3 输入框 (Input)

- **默认态**: 边框 `#D9D9D9`, 背景 `#FFFFFF`, 高度 34px, 圆角 2px, 内边距 0 12px
- **聚焦态**: 边框 `#1E88E5`, 无外发光, 过渡 0.2s
- **错误态**: 边框 `#F44336`, 无外发光, 下方红色错误文字 12px
- **禁用态**: 背景 `#F5F5F5`, 文字 `#BFBFBF`, cursor: not-allowed
- **搜索输入框**: 左侧搜索图标 16px, 右侧清除按钮, 输入时实时搜索 (debounce 300ms)

### 3.4 下拉选择 (Select)

- **触发器**: 与输入框相同样式，右侧下箭头图标 16px
- **下拉面板**: 圆角 4px, 无阴影, 1px 边框 `#E8E8E8`, 最大高度 256px 内滚动
- **选项**: 高度 34px, 悬停背景 `#E3F2FD`, 选中项左侧勾选图标, 文字 14px
- **分组选项**: 组标题 12px 字号, 颜色 `#8C8C8C`, 上方 8px 间距

### 3.5 表格 (DataTable)

- **表头**: 背景 `#F5F5F5`, 文字 13px font-weight 500, 高度 40px, 底部 1px 边框 `#E8E8E8`
- **数据行**: 高度 48px, 字号 13px, 悬停背景 `#F5F5F5`, 选中背景 `#E3F2FD`
- **斑马纹**: 奇数行 `#FFFFFF`, 偶数行 `#FAFAFA` (可选)
- **边框**: 水平 1px `#E8E8E8`, 无垂直边框
- **空状态**: 居中插图 + "暂无数据" 文字, 颜色 `#8C8C8C`, 插图尺寸 120px
- **列宽拖拽**: 拖拽手柄在列右侧边缘, 宽度 4px, 悬停显示 `#1E88E5` 指示线

### 3.6 标签页 (Tabs)

- **标签样式**: 文字 14px, 默认颜色 `#8C8C8C`, 激活颜色 `#1E88E5` font-weight 500
- **指示条**: 底部 2px 高度, 颜色 `#1E88E5`, 宽度跟随文字, 过渡动画 0.3s
- **内容切换**: 淡入过渡, `opacity 0 → 1, transform translateY(4px) → translateY(0)`, 200ms

### 3.7 对话框 (Modal / Dialog)

- **遮罩**: `rgba(0, 0, 0, 0.45)`, 淡入 200ms
- **容器**: 圆角 6px, 无阴影, 1px 边框 `#E8E8E8`, 最大宽度 680px
- **标题**: 16px font-weight 600, 颜色 `#1F1F1F`, 底部 1px 分割线 `#E8E8E8`
- **内容区**: 内边距 16px, 底部间距 16px
- **底部操作栏**: 右对齐按钮组, 间距 8px, 上方 1px 分割线
- **进入动画**: 纯淡入, `opacity 0 → 1`, 200ms ease-out

### 3.8 抽屉 (Drawer)

- **容器**: 宽度 420px (默认), 背景 `#F5F5F5`, 右侧进入
- **头部**: 背景 `#FFFFFF`, 内边距 16px, 标题 16px font-weight 600
- **内容区**: 内边距 16px, 可滚动
- **进入动画**: 从右侧滑入, `transform translateX(100%) → translateX(0)`, 300ms cubic-bezier(0.4, 0, 0.2, 1)

### 3.9 标签 (Tag)

| 类型 | 背景 | 文字 | 边框 | 圆角 |
|-----|------|------|------|------|
| Primary | `#E3F2FD` | `#1E88E5` | 无 | 0px |
| Success | `#E8F5E9` | `#4CAF50` | 无 | 0px |
| Warning | `#FFF3E0` | `#FF9800` | 无 | 0px |
| Error | `#FFEBEE` | `#F44336` | 无 | 0px |
| Default | `#F5F5F5` | `#8C8C8C` | 无 | 0px |

高度 24px, 内边距 0 8px, 字号 12px

### 3.10 头像 (Avatar)

- **尺寸**: 24px (列表内), 32px (评论/跟进), 40px (侧边栏), 64px (个人中心)
- **圆角**: 50%
- **默认背景**: `#1E88E5`, 文字 `#FFFFFF`
- **带在线状态**: 右下角 8px 绿色圆点 `#4CAF50`, 边框 2px 白色

### 3.11 空状态 (Empty State)

- **插图**: SVG 线性风格, 尺寸 160px × 120px, 颜色 `#D9D9D9`
- **标题**: 14px, 颜色 `#8C8C8C`, 下方间距 8px
- **描述**: 12px, 颜色 `#BFBFBF`, 下方间距 16px
- **操作按钮**: Primary Outline 按钮

### 3.12 面包屑 (Breadcrumb)

- **文字**: 13px, 颜色 `#8C8C8C`
- **当前页**: 颜色 `#1F1F1F`, font-weight 500
- **分隔符**: `/` 符号, 颜色 `#D9D9D9`, 间距 4px
- **可点击项**: 悬停颜色 `#1E88E5`

## 4. Interaction — 交互与动效

### 4.1 页面加载

- **首屏加载**: 顶部 NProgress 进度条 (颜色 `#1E88E5`), 高度 2px, 从左侧到右侧填充, 加载完成后淡出
- **骨架屏 (Skeleton)**: 列表页加载时展示骨架屏占位，脉冲闪烁动画
  - 背景: `#E8E8E8` → `#F5F5F5` 循环渐变
  - 动画: `pulse 1.5s ease-in-out infinite`
  - 表格骨架: 表头行 + 5 行数据行占位矩形, 高度匹配实际行高 (48px)
  - 卡片骨架: 矩形 4px 圆角, 宽度 280px, 高度 160px
- **延迟策略**: 加载 > 200ms 才显示骨架屏, 避免闪烁

### 4.2 页面切换

- **路由切换**: 内容区纯淡入, `opacity 0 → 1`, 150ms ease-out
- **Tab 标签页切换**: 内容淡入, `opacity 0 → 1`, 100ms, 无位移
- **面包屑导航返回**: 无动画 (即时加载)

### 4.3 列表操作

- **行悬停**: 背景色过渡 `background-color 0.15s ease`, 从 `#FFFFFF` → `#F5F5F5`
- **行选中**: 背景 `#E3F2FD`, 左侧出现 3px 主色指示条, 指示条从上到下扩展动画 200ms
- **行删除**: 纯淡出, `opacity 1 → 0`, 200ms, 剩余行上移填补空位 200ms
- **批量操作栏**: 从底部滑入, `transform translateY(100%) → translateY(0)`, 200ms, 固定在列表底部, 高度 56px, 背景 `#FFFFFF`, 1px 顶部边框 `#E8E8E8`, 无阴影

### 4.4 看板拖拽

- **拖拽开始**: 卡片边框变为主色 `#1E88E5`, 轻微上移 `translateY(-2px)`, 无旋转, 过渡 150ms
- **拖拽中**: 卡片半透明 (opacity 0.7), 原位留下虚线占位框 (border: 1px dashed `#D9D9D9`, border-radius 4px)
- **放置目标区**: 列背景 `#E3F2FD`, 过渡 150ms
- **拖拽结束**: 卡片归位动画, `transform → none, opacity → 1`, 150ms ease-out
- **阶段计数更新**: 数字直接切换，无滚动动画（扁平风格不使用拟物动效）

### 4.5 表单交互

- **输入聚焦**: 边框颜色过渡 `border-color 0.15s ease`, 无外发光
- **校验反馈**: 错误信息从下方展开, `max-height 0 → 24px, opacity 0 → 1`, 150ms
- **必填标识**: 字段标签前红色星号 `*`, 字号 14px, 颜色 `#F44336`
- **自动保存提示**: 右下角 Toast "已自动保存", 淡入 150ms → 停留 2s → 淡出 150ms

### 4.6 模态/抽屉

- **打开**: 
  - Modal: 遮罩淡入 150ms + 容器纯淡入 150ms
  - Drawer: 遮罩淡入 150ms + 容器从右侧滑入 200ms
- **关闭**:
  - Modal: 容器淡出 150ms + 遮罩淡出 100ms
  - Drawer: 容器向右滑出 200ms + 遮罩淡出 100ms
- **确认关闭**: 若表单有未保存修改, 弹出二次确认 Popover "确认关闭？未保存的数据将丢失"

### 4.7 数据加载状态

- **按钮加载态**: 文字替换为 Loading 旋转图标 (16px) + "处理中...", 按钮宽度不变, 禁用点击
- **列表加载更多**: 底部显示加载指示器 (三点脉冲动画), 无限滚动触发阈值距底部 100px
- **导出任务**: 异步任务, 提交后右上角 Toast "导出任务已创建, 请在导出中心查看", 进度条在导出中心展示
- **全局搜索**: 输入 debounce 300ms 后触发, 搜索中显示 Loading Spinner, 结果区模块 Tab 显示匹配数量徽标

### 4.8 微交互

- **收藏/取消收藏**: 星标图标颜色切换, `#8C8C8C` ↔ `#FF9800`, 无缩放动画
- **数量变更**: 数字直接切换，无滚动动画（扁平风格）
- **Toast 通知**: 纯淡入淡出, `opacity 0 → 1`, 150ms; 停留 3s, 自动淡出 150ms; 成功绿色/警告橙色/错误红色/信息蓝色左侧 4px 指示条
- **下拉展开**: 高度从 0 展开至内容高度, `max-height 0 → auto`, 200ms ease-out, 配合 opacity 0 → 1
- **侧边栏折叠**: 宽度过渡 `width 180px → 56px`, 200ms ease, 文字淡出 → 图标居中

## 6. 页面级设计描述示例

### 6.1 工作台首页 (Workbench)

顶部区域展示 4 个统计卡片（今日待办数、本周新增线索、本月赢单金额、逾期回款数），卡片采用白底 + 1px 边框 `#E8E8E8` + 4px 圆角，数值使用 24px SemiBold 主色，标签 12px `#8C8C8C`。中部为跟进计划列表（紧凑模式，行高 40px），右侧为快捷操作面板。底部为数据概览图表区（ECharts 折线图/柱状图，主色系填充）。页面加载时卡片依次淡入，间隔 60ms，形成级联进入效果。

### 6.2 线索/客户列表页

顶部面包屑 + 标题行，右侧"新增线索"Primary 按钮 + "导入"Outline 按钮 + "导出"Text 按钮。下方筛选栏包含：状态下拉、负责人下拉、创建时间范围选择器、关键词搜索框（带左侧搜索图标）、高级筛选折叠按钮。视图切换器（列表/看板）在筛选栏右侧。列表视图为标准 DataTable，支持多选与批量操作。看板视图为多列卡片，每列顶部显示阶段名称 + 数量徽标。切换视图时内容区淡入过渡。

### 6.3 客户详情页

顶部客户信息卡片（名称 20px SemiBold、状态 Tag、负责人头像、创建时间），右上角操作按钮组（编辑、转客户、移入公海）。下方 Tab 标签页切换：基本信息（动态表单渲染）、联系人（子表格，可内联新增）、商机（列表或跳转）、合同（列表）、回款/发票/订单（统计摘要 + 明细列表）、跟进记录（时间线样式，左侧时间轴 + 右侧内容卡片）。Tab 切换内容区淡入过渡。

### 6.4 登录页

全屏布局，左侧 60% 为品牌视觉区（纯色背景 `#0B3D91` + 白色 Logo + 产品 Slogan），右侧 40% 为登录表单区（白色背景，居中卡片 400px 宽，圆角 6px，1px 边框 `#E8E8E8`，无阴影）。表单包含：账号输入框、密码输入框（带 RSA 加密）、记住我 Checkbox、登录 Primary 按钮（宽度 100%，高度 44px）、第三方登录入口（企微/钉钉/飞书图标按钮）。输入框聚焦时蓝色边框，无外发光，登录按钮悬停色加深，点击显示 Loading 旋转动画。

## 7. 响应式与移动端适配

| 断点 | 宽度范围 | 布局调整 |
|------|---------|---------|
| Desktop | ≥ 1280px | 三栏标准布局 |
| Tablet | 768px - 1279px | Sider 自动收起为图标模式, 筛选栏折叠为抽屉 |
| Mobile | < 768px | H5 独立页面 (Vant-UI), 底部 Tab 导航, 卡片式列表 |

移动端 H5 页面采用 Vant UI 组件库，保持相同色彩体系与间距规范，交互调整为触屏优先（更大的点击热区 44px、下拉刷新、底部安全区适配）。
